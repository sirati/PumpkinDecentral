If a process need to complete for progress run it as a single command that on completation of the goal or a timeout to detect a hang exits. Such proesses must be launched in foreground and not detached. running a task in the foreground that takes longer and get automatically backgrounded by the harness is NOT a violation and explicitly allowed.
