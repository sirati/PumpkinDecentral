Repeated polling or repeated queries of a background or detached process are forbidden. A single inspection or control action is allowed. Repeated use of `ps`, `pgrep`, log searches, tmux state inspection, or equivalent actions to monitor progress is strictly forbidden. If a process must complete before work can continue, run it as one foreground command that exits when the goal completes or when a timeout detects a hang. Do not deliberately detach such processes. A foreground task that runs longer than the tool harness's initial wait and is automatically assigned a session is explicitly allowed; wait for that same foreground command to finish without repeatedly polling it.
