# Cluster E2E scenario inventory

`untested` means no live execution has passed. A compiled fixture assertion or a unit test does not change that status. The primary fixture is `src/main.rs`; optional world-action contracts are in `src/spec_scenarios.rs` and individual invocations select them with `PUMPKIN_E2E_SPEC_SCENARIOS=<comma-separated IDs>`. An absent `/clustertest` hook is a failing selected scenario, never a pass. All setup hooks must submit through the same canonical `ActionInput` owner API used by gameplay and report completion only after accepted state. This document records fixture contracts and missing hooks without editing either signed-off plan.

State-mutating optional IDs should run in separate fixture invocations unless their preparation hooks explicitly restore the arena and player state between IDs. A passing compile means only that the client-side assertions are wired; no optional ID is marked passed until its live run and post-exit records both succeed.

## Mandatory full Java E2E orchestration

A baseline invocation is **partial coverage** even when it exits successfully. Full Java E2E acceptance requires the local Cargo binary `pumpkin-cluster-full-spec`, which enumerates every ID in `src/scenario_catalog.rs` and additionally requires baseline, normal-feature omission, radius-8/280-ms-RTT recovered timing comparison, delayed-one-chunk early streaming, and >1-MiB administration synchronization. Every case starts a fresh fixture; isolated membership and two-primary no-coholder topologies remain separate invocations. There is no scenario-selection or skip option in the full runner.

Build both fixture binaries locally (no Nix-store test output):

```sh
systemd-run --user --scope -p MemoryMax=10G -p MemorySwapMax=0 flock -x /tmp/pumpkin_agent_coordination/build.lock timeout 900s nix develop .#azalea -c cargo build --manifest-path tests/azalea-e2e/Cargo.toml --bins
```

After the server implementation and live testing are authorized, run the built foreground entrypoint with a feature-enabled server, separately built normal server, measured recovered handoff bound in milliseconds, and a new report directory:

